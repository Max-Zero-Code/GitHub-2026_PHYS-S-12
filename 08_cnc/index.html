Week 8: CNC

Design and fabricate something using one of the CNC machines in the lab. Make sure to include some kind of post processing in your design.

CNC Assignment

the first thing we had to do before even starting the CNC part of the asignment was creating the file that would be cut by the machine. we planned on maing a PCB for the driver circuit of a stepper motor. To acomplish this task we used a regular Xiao seed studio Footprint and an A4988 driver footprnt. To design the pcb we used the Ki Cad the open software tool. First we created the schematic, following the PCB guide posted by the TA and the A4988 wiring guide on the website. then we did the wiring for the PCB, and created the foodprints for the connectors and the extra components like the rotary encoder and the connector for the DC 12v power supply.

then we uploded the exported drill files, that were Grb to an online tool that converted these files in to Black and white png's that the computer is able to read and render propperly. We transfered these png files to the cnc monofab milling machine and used the V drill bit to mill the traces, and the 1/32 bit to bothe cut out the holes and cut the pcb separate to the copper sheet.

Post Processing

post processing started with sanding down the back copper sheet to prevent short circuiting between components, and then wiping the pcb with alchohol. Finally we soldered a 100 uf capacitor, a 4x1 header pin set and the remaining missing wholes with socket wholes for the driver and the Xiao microcontroler.
